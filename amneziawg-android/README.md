# AWG eCubz — Root Multi-Profile AmneziaWG Client для Android

**AWG eCubz** — высокопроизводительный systemless/root клиент протокола **AmneziaWG (AWG)** для Android (Magisk, KernelSU, KernelSU Next, APatch) с поддержкой одновременной работы нескольких профилей, раздельной маршрутизацией приложений (Per-App Split Tunneling), полным набором параметров обфускации и адаптивным Material 3 веб-интерфейсом.

---

## Ключевые возможности

- **Одновременная работа нескольких профилей:**
  - Запуск независимых туннелей на выделенных интерфейсах (`awg0`, `awg1`, `awg2`, ...).
  - Индивидуальные таблицы маршрутизации (`table 201`, `table 202`, ...) и приоритеты Policy Routing.
  - Автоматическая изоляция маршрутов и исключение конфликтов при одновременной работе.

- **Полная поддержка всех параметров обфускации AmneziaWG 1.0:**
  - `Jc`, `Jmin`, `Jmax` — мусорные пакеты (Junk packets) перед хендшейком.
  - `S1`, `S2`, `S3`, `S4` — смещения длины пакетов (Init/Response/Cookie/Data).
  - `H1`, `H2`, `H3`, `H4` — кастомные типы заголовков сообщений.
  - `I1`, `I2`, `I3`, `I4`, `I5` — тяжелые полезные нагрузки обфускации (SIP, HTTP, RTP payloads любого размера).

- **Нативная раздельная маршрутизация приложений (Per-App Split Tunneling):**
  - **Include Apps:** перенаправление в туннель только выбранных приложений.
  - **Exclude Apps:** пропуск выбранных приложений мимо туннеля напрямую в Wi-Fi / мобильную сеть.
  - **All Traffic:** режим полного туннелирования всего устройства.
  - **Приоритет ядра Linux `uidrange` (Priority 9000):** прямое связывание сокетов приложений с адресом туннеля в обход системных ограничений Android.

- **Точечная маршрутизация по доменам (Domain-Based Routing):**
  - Точечное перенаправление трафика выбранных доменов в туннели или группы резервирования (HA-резерв) через LPM префиксные маршруты ядра Linux (`/32` и `/128`).
  - Глобальный список **Exclude** (высший приоритет): трафик к указанным доменам идет напрямую через физический шлюз (`dev wlan0` / `dev rmnet_data*`), обходя все туннели и таблицы.
  - Встроенные пресеты в один клик: «Банки и сервисы РФ» (Сбер, Т-Банк, ВТБ, Госуслуги, НСПК/СБП, Ozon, WB и др.), «Google Gemini / Claude», «OpenAI / ChatGPT».
  - Автоматическая защита от коллизий и пересечений: Exclude побеждает туннели, группы побеждают одиночные профили, доменная маршрутизация побеждает маршрутизацию приложений per-app.
  - Настраивается на вкладке «Домены» в WebUI и хранится в `/data/adb/amneziawg/domains.json`.

- **Группы резервирования (Failover):**
  - Набор приложений переключается между несколькими туннелями автоматически, когда эндпоинт текущего перестает пропускать трафик.
  - Все туннели группы подняты одновременно, поэтому переключение не требует переподключения.
  - Порядок участников задает приоритет; возврат на более приоритетный туннель выполняется после заданного времени непрерывного здоровья, чтобы мигающая блокировка не приводила к качелям.
  - Настраивается на вкладке «Группы» в WebUI: участники переупорядочиваются кнопками, состояние каждого видно сразу, маршрут можно снять и вернуть вручную.
  - Конфигурация хранится в `/data/adb/amneziawg/groups.json` и проверяется командой `awg-controller group-check`; при неудачной проверке WebUI откатывает файл.

- **Сетевой страж (KillSwitch):**
  - Блокировка утечек реального IP-адреса на уровне ядра (`iptables REJECT`).
  - Защита усиливается при потере туннеля: если watchdog исчерпал попытки восстановления, трафик приложений профиля блокируется, а не переводится на прямой канал.
  - Блокировка ставится на ранней стадии загрузки (`post-fs-data`), до появления сети, и снимается только по явному действию пользователя (выключение профиля) либо при переходе в доверенную Wi-Fi сеть.

- **Встроенный сканер QR-кодов:**
  - Быстрый импорт конфигураций AmneziaWG / WireGuard через диалог камеры или выбор скриншота из галереи.

- **Material 3 Expressive WebUI:**
  - Современный темный интерфейс с фиксированной нижней панелью навигации.
  - Мониторинг в реальном времени: статус хендшейка, пинг, счетчики переданного и принятого трафика (RX/TX).
  - Просмотр и фильтрация системного журнала работы.

- **Совместимость с модулями обхода замедлений (Zapret / NFQWS):**
  - Встроенный сквозной пропуск пакетов туннеля через цепочки NFQUEUE.

## Требования

- **Root-менеджер:** KernelSU, KernelSU Next, APatch или Magisk (v24.0+).
- **Архитектура:** `arm64-v8a`, `armeabi-v7a`, `x86`, `x86_64`.
- **ОС:** Android 9.0 – 16.0.

## Установка

1. Скачайте актуальный ZIP-архив из раздела [Releases](https://github.com/AntikFull/root_moduls/releases).
2. Установите архив через Magisk App, KernelSU Manager или APatch.
3. Перезагрузите устройство.
4. Откройте WebUI модуля в меню менеджера (кнопка «Настройка» / «Открыть WebUI»).

## Удаление

При удалении модуля снимаются все правила `iptables` и `ip rule`, возвращается
исходное значение `rp_filter` и очищаются рабочие каталоги.

Конфигурации профилей **намеренно сохраняются**: каталог
`/data/adb/amneziawg/profiles` содержит файлы `.conf` с приватными ключами, и
их удаление при переустановке модуля означало бы безвозвратную потерю данных.

Полное удаление вместе с ключами выполняется вручную:

```sh
rm -rf /data/adb/amneziawg
```

## Диагностика

Журнал модуля: `/data/adb/amneziawg/logs/awg-controller.log` (ротация при 512 КБ,
предыдущая часть — `awg-controller.log.1`).

Состояние туннелей: `awg-controller status` или `awg status json`.

Проверка пересечения приложений между профилями: `awg-controller check-conflicts`.

Сброс блокировки watchdog: `awg-controller reset-failures all`.

### Группы резервирования

Проверка конфигурации: `awg-controller group-check` (ненулевой код возврата при
противоречиях). Состав группы по приоритету: `awg-controller group-members <имя>`.

Текущее состояние участника: файл `/data/adb/amneziawg/run/<профиль>.routedown`
означает, что маршрут снят и трафик группы идет через следующего участника.

Ручное переключение: `awg-controller route-down <профиль>` и `route-up <профиль>`.

### Маршрутизация по доменам

Проверка конфигурации: `awg-controller domains-check` (ненулевой код возврата
только при настоящих ошибках; пересечения выводятся как предупреждения).

Немедленное обновление адресов: `awg-controller domains-apply`. Без явного
вызова повторный резолв выполняется не чаще `refresh_minutes` из
`domains.json` (по умолчанию 30 минут), но изменение конфигурации, запуск или
остановка туннеля и смена сети применяются сразу.

Текущий набор поставленных маршрутов: `/data/adb/amneziawg/run/domains.routes`.
