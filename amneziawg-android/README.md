# AWG eCubz — Root Multi-Profile AmneziaWG Client для Android

**AWG eCubz** — высокопроизводительный systemless/root клиент протокола **AmneziaWG (AWG)** для Android (Magisk, KernelSU, KernelSU Next, APatch) с поддержкой одновременной работы нескольких профилей, раздельной маршрутизацией приложений (Per-App Split Tunneling), полным набором параметров обфускации и адаптивным Material 3 веб-интерфейсом.

---

## Ключевые возможности

- **Одновременная работа нескольких профилей:**
  - Запуск независимых туннелей на выделенных интерфейсах (`awg0`, `awg1`, `awg2`, ...).
  - Индивидуальные таблицы маршрутизации (`table 201`, `table 202`, ...) и приоритеты Policy Routing.
  - Автоматическая изоляция маршрутов и исключение конфликтов при одновременной работе.

- **Полная поддержка всех параметров обфускации AmneziaWG 1.0:**
  - `Jc`, `Jmin`, `Jmax` — мусорные пакеты (Junk packets) перед хендшейком.
  - `S1`, `S2`, `S3`, `S4` — смещения длины пакетов (Init/Response/Cookie/Data).
  - `H1`, `H2`, `H3`, `H4` — кастомные типы заголовков сообщений.
  - `I1`, `I2`, `I3`, `I4`, `I5` — тяжелые полезные нагрузки обфускации (SIP, HTTP, RTP payloads любого размера).

- **Нативная раздельная маршрутизация приложений (Per-App Split Tunneling):**
  - **Include Apps:** перенаправление в туннель только выбранных приложений.
  - **Exclude Apps:** пропуск выбранных приложений мимо туннеля напрямую в Wi-Fi / мобильную сеть.
  - **All Traffic:** режим полного туннелирования всего устройства.
  - **Приоритет ядра Linux `uidrange` (Priority 9000):** прямое связывание сокетов приложений с адресом туннеля в обход системных ограничений Android.

- **Сетевой страж (KillSwitch):**
  - Блокировка утечек реального IP-адреса на уровне ядра (`iptables REJECT`) при падении или остановке туннеля.

- **Встроенный сканер QR-кодов:**
  - Быстрый импорт конфигураций AmneziaWG / WireGuard через диалог камеры или выбор скриншота из галереи.

- **Material 3 Expressive WebUI:**
  - Современный темный интерфейс с фиксированной нижней панелью навигации.
  - Мониторинг в реальном времени: статус хендшейка, пинг, счетчики переданного и принятого трафика (RX/TX).
  - Просмотр и фильтрация системного журнала работы.

- **Совместимость с модулями обхода замедлений (Zapret / NFQWS):**
  - Встроенный сквозной пропуск пакетов туннеля через цепочки NFQUEUE.

## Требования

- **Root-менеджер:** KernelSU, KernelSU Next, APatch или Magisk (v24.0+).
- **Архитектура:** `arm64-v8a`, `armeabi-v7a`, `x86`, `x86_64`.
- **ОС:** Android 9.0 – 16.0.

---

## Установка

1. Скачайте актуальный ZIP-архив из раздела [Releases](https://github.com/AntikFull/root_moduls/releases).
2. Установите архив через Magisk App, KernelSU Manager или APatch.
3. Перезагрузите устройство.
4. Откройте WebUI модуля в меню менеджера (кнопка «Настройка» / «Открыть WebUI»).
