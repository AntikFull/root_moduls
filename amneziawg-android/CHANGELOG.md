# История изменений AWG eCubz

## v1.0.9 (1009)

- Внедрена функция **«Доверенные Wi-Fi сети (Smart Pause)»** раздельно для каждого профиля:
  - Автоматический перевод профиля в режим сна при подключении к доверенным сетям (трафик приложений идет напрямую).
  - Мгновенное пробуждение туннеля и восстановление маршрутизации при переключении на мобильную сеть или другой Wi-Fi.
  - Кнопка «+ Текущая сеть» в окне настроек для добавления текущего SSID в один клик.
  - Отображение статуса сна `Спит (SSID)` на панели управления.

## v1.0.8 (1008)

- Название обновлено на **AWG eCubz**.
- Нативная маршрутизация `uidrange` (Priority 9000).
- Автоматический `PersistentKeepalive = 25` в ядре CLI.
- Полный обход фильтрации IPv6 для Zapret/NFQWS.
