## <a name="русский"></a> 🇷🇺 Описание (Russian)

**Magisk DNS Servers** — коллекция модулей для перенаправления и настройки системных DNS-серверов в Android через Magisk, KernelSU и APatch.

### 🌐 Поддерживаемые DNS-провайдеры:
- **Cloudflare (1.1.1.1)** — Высокая скорость и приватность.
- **Google (8.8.8.8 / 8.8.4.4)** — Быстродействие и стабильность.
- **AdGuard DNS** — Блокировка рекламы, вредоносных сайтов и трекеров.
- **Quad9 (9.9.9.9)** — Защита от фишинга и вредоносного ПО.
- **Yandex DNS** — Фильтрация рекламы и семейный режим.
- **OpenDNS, Baidu, Neustar, UncensoredDNS, Verisign, DNS.WATCH**.

### 🛠️ Установка:
1. Выберите нужный DNS-провайдер из соответствующей директории.
2. Установите ZIP-архив модуля через **Magisk / KernelSU / APatch**.
3. Перезагрузите устройство.

## <a name="english"></a> 🇬🇧 Description (English)

**Magisk DNS Servers** is a collection of modules designed to override system DNS resolvers on Android via Magisk, KernelSU, and APatch.

### 🌐 Supported DNS Providers:
- **Cloudflare (1.1.1.1)** — Speed and security.
- **Google (8.8.8.8 / 8.8.4.4)** — Reliable global DNS.
- **AdGuard DNS** — Integrated ad-blocking and anti-tracking.
- **Quad9 (9.9.9.9)** — Phishing and malware protection.
- **Yandex DNS** — Ad filtering and family security.
- **OpenDNS, Baidu, Neustar, UncensoredDNS, Verisign, DNS.WATCH**.

### 🛠️ Installation:
1. Choose your preferred DNS provider directory.
2. Flash the module ZIP archive via **Magisk / KernelSU / APatch**.
3. Reboot your device.
