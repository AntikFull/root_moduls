Zapret2 eCubz v2.6.13 (2613)

UI/compatibility release поверх стабильной сетевой базы v2.6.12.

  • Material 3 Expressive-inspired WebUI: adaptive containers, richer tonal palette, shape morphing, ripple/press feedback, snackbar, loading states, active section navigation and reduced-motion support.
  • Compatibility fallback AUTO → SIMPLE больше не помечается как runtime degradation, если обязательная рабочая база исправна.
  • Capability status: nf_conntrack_acct, CONNMARK, xt_connbytes, NFQUEUE, owner.
  • Hotspot/VPN/DNS dependent controls получают корректное disabled-состояние.
  • Проверена связка всех WebUI actions с backend-командами, JSON endpoints и list toggles.
  • Исправлен validator кнопки сохранения стратегий: корректные аргументы с -- теперь принимаются, shell-метасимволы отклоняются.
  • Сетевая маршрутизация/VPN role detector v2.6.12 не изменялись.
