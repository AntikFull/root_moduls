# Zapret2 eCubz v2.9.0 — audit report

## Результат

SMART_ACTIVE переведён с жёстко заданного списка на пользовательский каталог
`strategies`. Файлы `strategy_<положительное число>` сортируются численно, поэтому
`strategy_2` идёт раньше `strategy_10`. Пропуски и номера больше 99 разрешены.

Стартовая очередь:

1. `strategy_1` — COMPAT_FAKE;
2. `strategy_2` — SIMPLE_ALT4;
3. `strategy_3` — SPLIT_SAFE;
4. `strategy_4` — USER_PADENCAP_TLSMOD;
5. `strategy_5` — USER_PADENCAP_MD5;
6. `strategy_6` — USER_MIDSNI_MD5.

## Безопасность формата

- файлы не source-ятся и не проходят через eval;
- допустимы только аргументы из ограниченного набора ASCII-символов;
- запрещены `--qnum`, `--user`, `--daemon`, `--pidfile`, `--lua-init`, `--debug`, `--new`;
- symlink и некорректные имена игнорируются;
- размер одного файла ограничен 16 КиБ, итоговая строка аргументов — 8 КиБ;
- короткой стратегии автоматически добавляются TLS/443, out-range и payload;
- изменение состава/содержимого входит в ключ per-network кэша;
- применённая подпись хранится в health.env, поэтому изменение содержимого выбранного
  файла вызывает быстрый reload, даже если его имя осталось прежним.

## Upgrade

При первом обновлении со старой версии устанавливаются шесть файлов по умолчанию.
При последующих обновлениях каталог пользователя сохраняется целиком без добавления
новых дефолтов и без перезаписи содержимого. Старое значение
`AUTO_PROFILE_DEFAULT=COMPAT_FAKE` мигрирует в `strategy_1`.

## Проверки на OnePlus PJA110 / Android 16 / KernelSU Next

- Android `sh -n`: изменённые shell-скрипты проходят;
- WebUI JavaScript: `node --check` проходит;
- все шесть файлов: PARSE_OK;
- все шесть файлов: nfqws2 START_OK на отдельной очереди 299;
- крайние случаи: числовой порядок, пропуски, strategy_99, запрет process-аргументов,
  игнорирование symlink — проходят;
- реальный SMART_ACTIVE на MegaFon: strategy_1 / COMPAT_FAKE, PASS;
- после теста: READY, HEALTH=OK, AUTO_STATUS=CACHED, nfqws2 и watchers живы;
- cold boot выявил только рассинхронизацию COMPAT_NOTES=NO_NETWORK при уже
  обновлённом AUTO_STATUS=CACHED; стабильный релиз синхронизирует и это поле;
- временная очередь 201 удалена после probe, основной процесс не потерян.

Телефон не перезагружался во время разработки. Финальная установка и один reboot
выполняются только после сборки и проверки ZIP.
