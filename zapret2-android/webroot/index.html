О проекте Zapret2 eCubz

Разработчик модуля: eCubz

Канал обновлений: t.me/module_ecubz

Чат сообщества: t.me/eCubz

Движок AntiDPI: nfqws2 (bol-van), AmneziaWG v3

Разработано с фокусом на 100% автономность, безопасность и энергоэффективность Android.

Структура каталогов и ручная настройка
• /data/adb/zapret2/ru/ — конфигурации .conf для основного туннеля AWG99.
• /data/adb/zapret2/geo/ — конфигурации .conf для геоблок-туннеля AWG98.
• /data/adb/modules/zapret2-android/zapret2.conf — основной конфигурационный файл модуля.
• /data/adb/modules/zapret2-android/lists/geo_warp.list — список доменов для геоблока AWG98.
