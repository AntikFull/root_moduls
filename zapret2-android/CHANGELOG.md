# Список изменений zapret2-android v3.3.2 (3220)

- **WARP / AmneziaWG adaptive recovery:**
  - Исправлены неопределённые `WARP_RUNTIME_CONF` и `WARP_RULE_STATE`, из-за которых WebUI мог получать `can't create : No such file or directory` при применении WARP.
  - Новый `warp.conf` создаётся индивидуально на устройстве только после успешной регистрации public key; при ошибке регистрации фальшивый профиль не сохраняется.
  - Свежий профиль стартует в BASIC без `I1/I2`. SIP-пакеты `I1/I2` включаются только после провала полного BASIC-цикла.
  - Добавлен воспроизводимый adaptive-поиск: пользовательский J-профиль → официальные WARP WireGuard-порты 2408/500/1701/4500 → несколько Jc/Jmin/Jmax-профилей → SIP I1/I2 → повторный J/port цикл.
  - `S1-S4/H1-H4` не рандомизируются для Cloudflare WARP: сохраняется совместимость с обычным WireGuard peer (`S*=0`, `H1..H4=1..4`); адаптируются только client-side J* и I*.
  - Убраны случайные/неподтверждённые WARP endpoints и UDP 854 из adaptive-цикла. Рабочий adaptive step сохраняется и повторно используется.
  - WebUI показывает фактический BASIC/SIP режим и активный J-профиль; исправлены ложные значения Jc в подсказках.

# Список изменений zapret2-android v3.3.1 (3210)

- **Исправления по повторному полному аудиту v3.3.0:**
  - WebUI HTTP fallback синхронизирован с реальными командами контроллера и аргументами; write-команды только POST, без `eval`, wildcard CORS и без логина/пароля. Добавлена прозрачная CSRF-защита служебным заголовком WebUI.

  - WARP: атомарная синхронизация UID, динамические Android users, PID-owned/re-entrant lock, точная очистка policy rules, проверка маршрутизации, fail-closed IPv6, безопасная регистрация/rekey и DNS forcing для обычного UDP/TCP 53.
  - Удалён готовый `state/warp.conf` из релиза: приватный WARP-ключ теперь всегда создаётся индивидуально на устройстве.
  - Исправлены DIRECT+tethering NFQUEUE, IPv6 VPN leak guard, гонка `on_change`, транзакционное обновление app chains и диагностика/экспорт логов.
  - Удалены устаревшие AI Router cleanup-пути, broad process kill, `eval` в watcher/auto-select и неиспользуемые WARP-параметры.

# Список изменений zapret2-android v3.0.3 (3030)

- **Android 16 Cellular Interface Fix:** Исправлено определение активного интерфейса сотовой сети на Android 16 (ColorOS/OxygenOS), когда `dumpsys connectivity` возвращает `Active default network: none`.
- **Fast Background Cache Verification (Идея 1):** При восстановлении кэшированной стратегии модуль мгновенно применяет её без задержек, а в фоне выполняет быструю проверку связи (1 запрос к YouTube). Если оператор заблокировал стратегию, автоматически запускается полный переподбор и обновляется кэш.
- **Safe Fallback to COMPAT_FAKE (Идея 2):** Если во время переподбора стратегии не дали преимуществ, модуль автоматически откатывается на проверенный универсальный профиль `COMPAT_FAKE` (`strategy_2`), исключая падение сети.
- **Network Debounce / Hysteresis (Идея 3):** Добавлена задержка 3 секунды для объединения частых всплесков netlink-событий (переключение вышек сотовой связи / скачки SIM 1 <-> SIM 2).
- **Auto Cache Pruning (Идея 4):** Автоматическая очистка кэш-файлов сетей, не посещавшихся более 30 дней.
- **Re-entrant acquire_lock Fix:** Исправлена блокировка рекурсивного reload в `service.sh`, предотвращавшая запуск `nfqws2` при смене режимов DIRECT <-> DESYNC.
