# Список изменений Zapret2 eCubz v3.0.0 (3000)

- Внедрен `probe_hosts.list` — простой вынос доменов для активного тестирования сети (probe).
- Внедрен `wifi_direct_ssids.list` — автоматическое выключение обхода (режим DIRECT) на доверенных Wi-Fi сетях по SSID.
- Обновлены списки приложений: внесены реальные пакеты заблокированных в РФ сервисов из Google Play (Mega.nz, Instagram, Threads, X/Twitter, Facebook, Discord, Reddit, Spotify, Twitch, Signal).
- Убраны гео-заблокированные на стороне сервиса ИИ-приложения (ChatGPT, Claude), требующие прокси/VPN.
- Режим DIRECT динамически отключает обход на нефильтрованной сети и на доверенном Wi-Fi.
