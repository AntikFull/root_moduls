# Список изменений zapret2-android v3.0.3 (3030)

- **Android 16 Cellular Interface Fix:** Исправлено определение активного интерфейса сотовой сети на Android 16 (ColorOS/OxygenOS), когда `dumpsys connectivity` возвращает `Active default network: none`.
- **Fast Background Cache Verification (Идея 1):** При восстановлении кэшированной стратегии модуль мгновенно применяет её без задержек, а в фоне выполняет быструю проверку связи (1 запрос к YouTube). Если оператор заблокировал стратегию, автоматически запускается полный переподбор и обновляется кэш.
- **Safe Fallback to COMPAT_FAKE (Идея 2):** Если во время переподбора стратегии не дали преимуществ, модуль автоматически откатывается на проверенный универсальный профиль `COMPAT_FAKE` (`strategy_2`), исключая падение сети.
- **Network Debounce / Hysteresis (Идея 3):** Добавлена задержка 3 секунды для объединения частых всплесков netlink-событий (переключение вышек сотовой связи / скачки SIM 1 <-> SIM 2).
- **Auto Cache Pruning (Идея 4):** Автоматическая очистка кэш-файлов сетей, не посещавшихся более 30 дней.
- **Re-entrant acquire_lock Fix:** Исправлена блокировка рекурсивного reload в `service.sh`, предотвращавшая запуск `nfqws2` при смене режимов DIRECT <-> DESYNC.

# Список изменений Zapret2 eCubz v3.0.2 (3020)

- Устранено незащищенное переходное окно при смене сети: при переключении с Wi-Fi (DIRECT) на мобильную сеть модуль немедленно активирует дефолтный защитный профиль (PROBING) на время тестирования стратегий.
- Исправлена отображаемая информация в WebUI во время пробирования новой сети.
- Исправлена совместимость скрипта установки (update-binary) с KernelSU, KernelSU Next и APatch.
- Добавлен надежный поиск `unzip` и `busybox` в установщике.
- Добавлено восстановление после зависшего reload и подробные этапы очистки firewall в startup state/boot trace.
- Исправлены повреждённые русские сообщения состояния и ошибки WebUI/CLI.
- Восстановлены оригинальные ELF-бинарники `nfqws2` для arm, arm64, x86 и x86_64, повреждённые ошибочной нормализацией окончаний строк.
- Внедрен `probe_hosts.list` — простой вынос доменов для активного тестирования сети (probe).
- Внедрен `wifi_direct_ssids.list` — автоматическое выключение обхода (режим DIRECT) на доверенных Wi-Fi сетях по SSID.
- Обновлены списки приложений: внесены реальные пакеты заблокированных в РФ сервисов из Google Play (Mega.nz, Instagram, Threads, X/Twitter, Facebook, Discord, Reddit, Spotify, Twitch, Signal).
- Убраны гео-заблокированные на стороне сервиса ИИ-приложения (ChatGPT, Claude), требующие прокси/VPN.
- Режим DIRECT динамически отключает обход на нефильтрованной сети и на доверенном Wi-Fi.
