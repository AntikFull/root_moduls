# Отчет об аудите Zapret2 eCubz

SMART_ACTIVE работает со списком подхватываемых файлов стратегий в папке `strategies`.
Файлы `strategy_<номер>` сортируются численно: `strategy_2` идет перед `strategy_10`. Лимит в папке — 99 стратегий.

## Порядок стратегий:

1. `strategy_1` — DIRECT (обход не требуется / незаблокированная сеть);
2. `strategy_2` — SMART TLS;
3. `strategy_3` — SPLIT SAFE;
4. `strategy_4` — USER PADENCAP TLSMOD;
5. `strategy_5` — USER PADENCAP MD5;
6. `strategy_6` — USER MIDSNI MD5.

## Особенности архитектуры:
- Чтение файлов без вызова eval;
- Названия стратегий парсятся из валидных ASCII-комментариев;
- Фильтрация аргументов `--qnum`, `--user`, `--daemon`, `--pidfile`, `--lua-init`, `--debug`, `--new`;
- Исключена обработка симлинков вне папки;
- Лимит вывода логов 16 КБ, задержка очистки до 8 КБ;
- Проверка стратегий выполняет тесты на TLS/443;
- Результаты подбора сохраняются в per-network кэш;
- Статус работы записывается в `health.env`.

## Проверка:
- Android `sh -n`: shell-синтаксис проверен;
- WebUI JavaScript: проверен;
- Файлы конфигурации и скрипты сохранены в кодировке UTF-8 без BOM с Unix (LF) переносами строк.
