# zapret2-android (AntiDPI + Cloudflare WARP Tunnel + Tethering)

Продвинутый системный root-модуль обхода DPI-блокировок и избирательного туннелирования для Android 7.0–16 (KernelSU / KernelSU Next / Magisk / APatch).

Автор: **eCubz** ([Telegram](https://t.me/eCubz))  
Канал и обновления: [https://t.me/module_ecubz](https://t.me/module_ecubz)

---

## Основные возможности

1. **Системный обход DPI (AntiDPI на базе nfqws2)**:
   - Обход блокировок и замедлений YouTube (включая 4K 60fps), Discord (голосовые и медиаканалы), Instagram, Twitter/X, мессенджеров и веб-сайтов.
   - Работает на уровне сетевого стека ядра (Netfilter / NFQUEUE), не создавая виртуальных VPN-интерфейсов на весь телефон.
   - Поддержка режимов SMART (авто-подбор стратегий под текущего провайдера), INCLUDE (выбранные приложения) и GLOBAL.

2. **Точечный туннель Cloudflare WARP (AmneziaWG v3)**:
   - Встроенный клиент AmneziaWG v3 для перенаправления только выбранных приложений (ChatGPT, Claude, Notion, зарубежные сервисы).
   - Адаптивный поиск серверов и портов Cloudflare (порты 2408, 500, 4500, 1701 и альтернативные пулы 188.114.97.1/188.114.96.1), устойчивый к блокировкам подсетей в РФ.
   - Защита от фрагментации MTU и поддержка маскировки Junk/SIP.

3. **Доверенные сети (Режим DIRECT)**:
   - Автоматическое отключение обхода при подключении к домашним Wi-Fi сетям, указанным в wifi_direct_ssids.list.
   - На доверенном Wi-Fi модуль полностью выгружает 
fqws2 и снимает правила фаервола, избегая конфликтов с обходом на роутере. При переходе на мобильную связь обход включается автоматически.

4. **Раздача интернета (Tethering / Hotspot)**:
   - Поддержка обхода блокировок на раздаче интернета по Wi-Fi, USB и Bluetooth без дополнительных настроек на подключенных ПК/ТВ.
   - Защита от утечек IPv6 (Fail-Closed) и совместимость с фиксацией TTL/Hop Limit.

5. **Удобный WebUI**:
   - Панель управления доступна локально прямо в браузере или через менеджеры модулей (MMRL, Magisk, KernelSU WebUI).
   - Управление списками приложений, статусом WARP, ручной запуск тестирования и переключение стратегий в один клик.

---

## Структура списков (lists/)

- pps.list / pps.user.list — список приложений для обхода AntiDPI.
- uto_apps.list — системный каталог популярных сервисов для режима SMART (обновляется при установке).
- warp_apps.list / warp_apps.user.list — приложения, направляемые в туннель Cloudflare WARP.
- exclude.list / exclude_domains.list — списки исключений (прямой доступ без обработки).
- wifi_direct_ssids.list — имена доверенных Wi-Fi сетей для режима DIRECT.
- dns.list / dns.user.list — пользовательские DNS-серверы.

*Все пользовательские списки, файлы конфигурации zapret2.conf, сохранённые ключи WARP и кастомные стратегии сохраняются при обновлении модуля.*

## Установка и совместимость

- **Поддерживаемые Root-менеджеры**: Magisk 20.4+, KernelSU, KernelSU Next, APatch.
- **Поддерживаемые архитектуры CPU**: ARM64 (aarch64), ARMv7 (armeabi-v7a), x86, x86_64.
- **Android**: 7.0 — 16 (с поддержкой OEM прошивок HyperOS, OneUI, ColorOS, OxygenOS, Pixel).
