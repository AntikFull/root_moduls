==============================================================================
 strategies/ — каталог стратегий обхода DPI
==============================================================================

КАК ЭТО РАБОТАЕТ
----------------
При смене сети модуль проверяет сайты из lists/probe_hosts.list БЕЗ обхода
(эталон), затем по очереди включает каждую стратегию и проверяет их снова.
Побеждает та, которая чинит больше всего сайтов и при этом не ломает уже
работавшие. Результат кэшируется отдельно для каждой Wi-Fi / мобильной сети
в state/auto-<ключ>.env.

ПОРЯДОК ПЕРЕБОРА
----------------
По возрастанию номера в имени файла: strategy_1, strategy_2, ... Ставьте
более лёгкие и совместимые стратегии раньше — перебор останавливается, как
только очередная стратегия починила ВСЁ.

ФОРМАТ ФАЙЛА
------------
    # NAME=ИМЯ_ПРОФИЛЯ        <- показывается в WebUI, [A-Za-z0-9_.-], до 64 символов
    # MODE=DIRECT             <- необязательно: «без обхода вообще»
    --lua-desync=...          <- аргументы nfqws2, по одному на строку

Если MODE=DIRECT, файл не должен содержать ни одного аргумента.
Если аргументы есть, а --filter-tcp / --filter-l7 / --out-range / --payload
не указаны, модуль сам подставит значения по умолчанию (443 / tls / -d10 /
tls_client_hello).

Запрещены аргументы, которыми управляет сам модуль: --qnum, --user, --daemon,
--pidfile, --lua-init, --debug, --new. Файл с ними будет отброшен целиком.

НУМЕРАЦИЯ
---------
    strategy_1  .. strategy_99    — встроенные. ПЕРЕЗАПИСЫВАЮТСЯ при обновлении
                                    модуля. Правки здесь не сохранятся.
    strategy_100 .. и выше        — ваши. Сохраняются при обновлении.

Хотите доработать встроенную стратегию — скопируйте её в strategy_1xx и
правьте копию:

    cp strategy_3 strategy_101

strategy_1 — это профиль DIRECT (обход не нужен). Не удаляйте его, если
пользуетесь энергосбережением на домашнем Wi-Fi: без него режим DIRECT
недоступен и модуль будет держать nfqws2 запущенным всегда.

ПРОВЕРКА
--------
После правки посмотрите logs/zapret2_auto.log — там видно, какие кандидаты
запускались и с каким результатом:

    result=START_FAILED   стратегия не запустилась (ошибка в аргументах)
    result=LUA_ERROR      nfqws2 упал на Lua-скрипте
    result=NO_PACKETS     правило не поймало ни одного пакета
    result=REGRESSION     сломала сайты, которые работали до неё
    result=SCORE fixed=N  починила N сайтов из эталона
