# Alice AI Bluetooth Auto-Launcher

**Кроссплатформенный модуль для Magisk, KernelSU, KernelSU Next и APatch**

Модуль отслеживает подключение Bluetooth-устройства (по умолчанию Яндекс Дропс `60:3D:61:B6:8B:00`), автоматически запускает приложение **Алиса AI** (`com.yandex.aliceapp`) в фоновом режиме (с мягким возвратом в предыдущее активное приложение через `BACK`), и корректно выгружает его при отключении.

## Ключевые особенности

- **Бесшовный фоновый запуск:** При подключении наушников приложение Алиса AI мгновенно стартует и возвращает фокус в предыдущее открытое приложение (кнопка `BACK`), не сбрасывая пользователя на рабочий стол.
- **Событийный режим работы:** Никакого лишнего опрашивания `pidof` или постоянных перезапусков. Модуль реагирует только на реальные события изменения состояния Bluetooth.
- **5-секундный защитный буфер отсоединения:** При кратковременных помехах Bluetooth выдерживается пауза и делается контрольная проверка перед остановкой приложения.
- **Локальное логирование:** Логи пишутся в `$MODDIR/debug.log` с автоматической ротацией (не засоряя `/sdcard`), логирование можно отключить в конфиге.
- **Гибкая конфигурация:** Все параметры вынесены в `config.conf`.

## Файл конфигурации (`config.conf`)

Конфигурационный файл расположен в директории модуля `/data/adb/modules/alice-bt-launcher/config.conf`:

```ini
# MAC-адрес целевых Bluetooth наушников
TARGET_MAC="60:3D:61:B6:8B:00"

# Имя пакета приложения
TARGET_PKG="com.yandex.aliceapp"

# Главный Activity приложения
TARGET_ACTIVITY="com.yandex.aliceapp/.ui.MainActivity"

# Режим сворачивания после запуска:
# 1 - возврат в предыдущее приложение (кнопка BACK / keyevent 4) - РЕКОМЕНДУЕТСЯ
# 2 - свернуть на рабочий стол (кнопка HOME / keyevent 3)
# 0 - оставить приложение на экране (не сворачивать)
MINIMIZE_MODE=1

# Интервал проверки состояния Bluetooth (в секундах)
CHECK_INTERVAL=3

# Задержка подстраховки при отключении наушников перед остановкой приложения (в секундах)
DISCONNECT_DELAY=5

# Вести ли отладочный лог в $MODDIR/debug.log (1 - да, 0 - нет)
ENABLE_LOGGING=1
```

## Установка

1. Скачайте последнюю версию релизного архива `alice-bt-launcher_v1.1.0_110.zip`.
2. Установите архив через менеджер **Magisk**, **KernelSU** или **APatch**.
3. Перезагрузите устройство.
4. При подключении настроенного Bluetooth-устройства Алиса запустится в фоновом режиме.
