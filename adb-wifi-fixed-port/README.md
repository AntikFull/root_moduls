# ADB WiFi On-Demand Fixed Port (5555)

**Универсальный модуль для Magisk, KernelSU, KernelSU Next и APatch**

Модуль решает проблему случайных 5-значных портов при включении встроенной отладки по Wi-Fi в Android 11–16, фиксируя постоянный стандартный порт **5555**, сохраняя при этом полную безопасность устройства.

## В чем проблема со стандартной отладкой Android 11+?

Начиная с Android 11, служба `AdbWifiService` при каждом включении тумблера «Отладка по беспроводной сети» генерирует **случайный порт** из диапазона `30000–50000`. Чтобы подключиться с ПК, пользователю приходится каждый раз смотреть на экран телефона, вводить новый порт и сопрягать устройство.

---

## Что делает данный модуль?

1. **Постоянный фиксированный порт 5555:**
   При включении отладки по Wi-Fi (через Настройки или плитку в шторке быстрых настроек) модуль мгновенно переводит ADB на статический порт `5555`. Вы подключаетесь одной привычной командой:
   ```bash
   adb connect 192.168.1.XX:5555
   ```
   (или просто `adb connect 192.168.1.XX`).

2. **Безопасность On-Demand (Защита от посторонних):**
   Порт `5555` **НЕ открыт постоянно**. Он открывается строго в момент, когда вы сами включаете тумблер отладки по Wi-Fi. Как только вы выключаете отладку — порт 5555 наглухо закрывается (`service.adb.tcp.port = -1`), блокируя любые сетевые подключения извне.

3. **Нулевая нагрузка на процессор и батарею:**
   Легковесный POSIX shell-сервис в цикле 1.5 сек считывает статус системного переключателя `adb_wifi_enabled`, потребляя 0.0% ресурсов CPU.

4. **Полная совместимость:**
   Работает на любых прошивках AOSP, ColorOS, OxygenOS, HyperOS, OneUI, PixelOS (Android 10, 11, 12, 13, 14, 15, 16) под управлением **Magisk**, **KernelSU** или **APatch**.

## Установка

1. Скачайте релизный архив `adb_wifi_fixed_port_v1.1_110.zip`.
2. Установите архив через менеджер **KernelSU**, **Magisk** или **APatch**.
3. Перезагрузите устройство.
4. Включите «Отладка по беспроводной сети» в настройках разработчика или плитку в шторке — порт 5555 станет доступен для подключения.
