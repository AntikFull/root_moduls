# AI Unblock RU

Устанавливайте ZIP через Magisk, KernelSU или APatch Manager.

AI Unblock открывает доступ к **ChatGPT, Gemini, Claude, Grok, NotebookLM и Google AI Studio** в поддерживаемых Android-приложениях.

Модуль работает автоматически после установки и перезагрузки. Системный DNS и файл hosts не меняются. Один ZIP подходит для ARM64, ARM, x86_64 и x86.

Ручной выбор и настройка не нужны. Модуль сам всё сделает.

Все диагностические логи сохраняются здесь:

`/sdcard/eCubz/AIUnblock/logs`

Или в файловом менеджере:

`Внутренняя память/eCubz/AIUnblock/logs`

При обращении в поддержку сразу отправьте содержимое этой папки.

Если нужно снять экстренную диагностику, нажмите **Action** у модуля в Magisk / KernelSU / APatch — отчет автоматически создастся в той же папке.
