# AI Unblock RU v2.2.2

Динамический Smart DNS DoH и точный SNI-маршрут Gemini/NotebookLM, независимый failover ChatGPT/Claude/Grok, hosts/AdBlock.

## Описание
Модуль для разблокировки ИИ-сервисов (Gemini, ChatGPT, Claude, Grok, NotebookLM) на смартфонах Android под управлением Magisk / KernelSU / APatch.

## Изменения в v2.2.2:
- Удален заставлявший отключаться файл skip_mount.
- Улучшен опрос кнопок громкости (choosekey без таймеров и перезагрузок).
- Полная изоляция от сторонних hosts (совместим с indhosts, AdAway и Systemless Hosts).
- Восстановлены бинарники и sha256 суммы.
