** AI Unblock RU v2.2.1**

Точечный обход региональных ограничений для **Gemini, NotebookLM, ChatGPT, Claude и Grok** через Smart DNS.

**Главное:**

- Только выбранные AI-приложения и домены — остальной трафик идёт напрямую.
- Автоматический подбор и TLS-проверка рабочих Smart DNS через DoH.
- Независимый failover для каждого AI-сервиса.
- Поддержка дополнительных пользователей, рабочих профилей и клонов.
- Собственные DoH, DoT и DNS можно добавить в `smartdns.user.conf` — файл сохраняется при обновлении.
- Системный Private DNS не изменяется, VPN не создаётся.

**Требования:** Android 10+, arm64, Magisk 20.4+ / KernelSU / APatch.

 Модуль предназначен только для поддерживаемых AI-сервисов и не заменяет полноценный VPN.
