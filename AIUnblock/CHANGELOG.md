# AI Unblock RU

## Версия v2.2.4

- **Безопасная адаптация под `bindhosts` без нарушения антибутлупа**:
  - Полностью вырезается папка `system/etc/hosts` при наличии `bindhosts`, в результате чего проверка `bindhosts` (`if [ -f "$module/system/etc/hosts" ]`) не срабатывает и `bindhosts` не отключает модуль.
  - Сохранена штатная работа системных защит от бутлупов (файлы `disable` не стираются принудительно).

## Версия v2.2.3

- **Автоматическое обнаружение конфликта hosts-модулей**: перед установкой (кнопками при выборе пунктов 1/2) и на каждой загрузке проверяется, не изменяет ли `/system/etc/hosts` уже другой активный модуль (AdAway, Systemless Hosts, bindhosts и т. п.).
  - При обнаружении конфликта на установке: hosts-компоненты AI Unblock (роутинг и AdBlock) автоматически отключаются, пользователю выводится причина; SNI/DNAT-роутинг продолжает работать без изменения hosts.
  - Проверка повторяется в `post-fs-data.sh`/`service.sh` на каждой загрузке — если конфликтующий модуль установлен позже, оверлей hosts модуля больше не создаётся, вместо разового решения при установке.
  - Логика вынесена в общий `lib/hosts_conflict.sh`, используемый всеми стадиями (`customize.sh`, `post-fs-data.sh`, `service.sh`, `action.sh`).
  - `action.sh` теперь показывает предупреждение о конфликте в статусе конфигурации.

## Версия v2.2.2

- **Удален маркерный файл skip_mount**: больше не блокирует монтирование модуля при установке в KernelSU/Magisk/APatch.
- **Исправлен опрос клавиш громкости (`choosekey`)**:
  - Удалён 4-секундный таймер автоматического выбора; скрипт ждёт явного нажатия кнопки.
  - Использован универсальный опрос `getevent -l -c 15` со считыванием сигнала со всех аппаратных контроллеров (включая разделенные контроллеры pmic_resin / gpio-keys на устройствах Qualcomm/Oplus).
  - Выбор кнопок не вызывает перезагрузки подсистемы ввода ядра и возвращает корректный статус `return 0` для `set -e`.
- **Полная изоляция монтирования hosts**:
  - Файлы хостов перенесены во внутреннюю директорию модуля (`etc/hosts.ai` и `etc/hosts.adblock`).
  - При отказе от хостов (оба пункта 0) полностью удаляется папка `system/etc/hosts`, благодаря чему Root-менеджер не создает оверлей hosts и не вступает в конфликт с AdAway / Systemless Hosts / bindhosts.
  - Удалены опасные деструктивные вызовы `umount -l /system/etc/hosts`.

## Версия v2.2.1

- Резолверы DoH, DoT и обычного DNS вынесены из `proxies.conf` в отдельный `smartdns.conf`.
- Добавлен сохраняемый при обновлении `smartdns.user.conf` для собственных резолверов.
- Конфигурация имеет безопасный построчный формат `DOH URL`, `DOT HOST` и `DNS IPv4` и не исполняется как shell-код.
- Пользовательские и штатные записи объединяются с удалением дублей; ошибочные строки пропускаются с записью в журнал.

## Версия v2.2.0

- Добавлено динамическое получение актуальных шлюзов через DoH сервисов `dns.malw.link`, `xbox-dns.ru` и `dns.geohide.ru`.
- DoH-запрос сразу проверяет реальное TLS-соединение с целевым доменом; статические IP теперь используются только как резерв.
- Независимые DoH-источники проверяются параллельно, чтобы один медленный сервер не увеличивал время переключения.
- Системный DNS Android не изменяется: новые адреса используются только существующими UID/DNAT/SNI-правилами AIUnblock.
- Терминология исправлена: адреса рассматриваются как шлюзы Smart DNS, а не как обычные прокси-серверы.

## Версия v2.1.4

- **Исправлен формат hosts**: принудительно удалены символы возврата каретки CRLF (`\r\n`), предотвращён регресс формата при конкатенации в `.merged_hosts`.
- **Снятие монтирования при деинсталляции**: в `uninstall.sh` добавлен отмонтирующий вызов `umount -l /system/etc/hosts`, чтобы не оставлять чужие монтирования после удаления модуля.
- **Корректный сброс правил iptables**: в `uninstall.sh` добавлены метки `-m comment --comment AIUNBLOCK` при вызовах `iptables -D`, исключая зависание хуков в `OUTPUT` и ошибки утилизации цепочек.
- **Полный сброс правил для Grok**: в `uninstall.sh` включены `ai.x.grok` и `GROK_DNAT` для очистки всех per-UID правил и цепочек.
- **Поддержка install.conf в post-fs-data.sh**: монтирование `hosts` при ранней загрузке теперь строго учитывает пользовательские настройки `ENABLE_HOSTS_ROUTING` и `ENABLE_ADBLOCK`.
- **Валидация конфигурации**: добавлены встроенная проверка значений `install.conf` на `0/1` и явное отмонтирование hosts в `action.sh`.
- **Единый лог UID**: в `refresh_uids()` в `service.sh` UID Grok логируется в общей строке со всеми ИИ-сервисами.
- **Документирование UDP-авторизации**: добавлены подробные комментарии к `AUTH_DNS` и `authorize_ips()` про механизм "прогрева" IP-адресов.
- **Информативное UI-предупреждение**: при установке выводится более понятное пояснение про доверие к узлам и проксирование запросов.

## Версия v2.1.3

- **Интерактивная настройка при установке**: добавлен выбор клавишами громкости (`Vol+` / `Vol-`) для независимого включения `hosts`-роутинга и блокировки рекламы `hosts.adblock`.
- **Быстрый переключатель `action.sh`**: добавлен скрипт быстрого переключения настроек в `install.conf` напрямую из Magisk / KernelSU без перезагрузки устройства.
- **Гибкий монтировщик `mount_hosts()`**: возвращена полноценная поддержка блокировки рекламы через слияние файлов в `.merged_hosts`.
- **Защита привязок iptables**: добавлены метки `-m comment --comment AIUNBLOCK` в `install_hooks()` для точной идентификации правил в цепочке `OUTPUT`.
- **Адаптивный UDP fallback**: добавлена проверка наличия `bash` перед вызовом нерасширенных сокетных подсистем `/dev/udp`.

## Версия v2.1.2

- **Внешняя конфигурация**: списки прокси-узлов и DNS вынесены в `proxies.conf`, добавлен файл примера `proxies.override.example`.
- **Проверка целостности**: добавлен файл `bin/SHA256SUMS` для валидации бинарников при копировании.
- **Рефакторинг**: функции управления DNAT-цепочками приедены к единому стандарту `apply_service_rules`.

## Версия v2.1.1

- Добавлен скрипт `post-fs-data.sh` с универсальным `mount --bind` файлового списка `hosts` для 100% совместимости с APatch, KernelSU, KernelSU Next и Magisk.

## Версия v2.1.0

- Исправлен формат встроенного `hosts`: теперь используется Unix LF без BOM, чтобы Android корректно сопоставлял доменные имена.
- Добавлены стандартные записи `127.0.0.1 localhost` и `::1 ip6-localhost`; рабочие строки `hosts` приведены к чистому ASCII.
- После перезагрузки заново восстанавливаются DNAT-цепочки ChatGPT, Claude и Grok, даже если выбранный адрес уже сохранён.
- Исправлена устаревшая подпись версии в журнале запуска supervisor.
- Добавлена поддержка официального приложения Grok (`ai.x.grok`).
- Для Grok теперь определяется отдельный UID и отдельное рабочее подключение.
- Адрес Grok проверяется отдельно, поэтому его сбой не влияет на Gemini, ChatGPT и Claude.
- Для Grok также ограничиваются QUIC и IPv6, чтобы приложение использовало обычный TCP через IPv4.
- В настройках языка Grok добавлен вместе с остальными отдельными AI-приложениями.

## Изменения с v1.9.1

- Исправлена проблема, из-за которой модуль мог не запускаться, если после перезагрузки интернет ещё не появился.
- Теперь модуль спокойно ждёт сеть и начинает проверку адресов только после её появления.
- Добавлен встроенный `curl`, поэтому отдельная установка этой команды больше не нужна.
- Добавлен встроенный hosts-файл из Unlock_AI, поэтому отдельный hosts-модуль не требуется.
- Добавлен локальный маршрутизатор для точной обработки соединений Gemini и NotebookLM.
- Обычный Google Поиск, Discover и Lens не отправляются через маршрут Gemini.
- Добавлена отдельная настройка соединения для NotebookLM.
- ChatGPT и Claude проверяются отдельно и могут использовать свои рабочие адреса.
- QUIC и IPv6 для поддерживаемых приложений ограничиваются, чтобы приложения использовали обычный TCP через IPv4.
- Глобальный язык, регион и системные свойства Android не изменяются.
- Язык меняется только у Gemini, NotebookLM, ChatGPT и Claude, если это поддерживается телефоном.
- После перезагрузки сохраняются выбранные рабочие адреса и настройки модуля.

## Исправления v2.0.1

- В локальный лог добавлена короткая диагностика маршрутов Gemini и NotebookLM.
