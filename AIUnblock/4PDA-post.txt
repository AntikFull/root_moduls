[b][color=teal]Описание[/color][/b]

[b]AI Unblock RU[/b] выборочно направляет HTTPS-трафик поддерживаемых AI-приложений через шлюзы Smart DNS. Остальной трафик телефона продолжает идти напрямую.

Модуль поддерживает:
[list]
[*][b]Gemini[/b] — com.google.android.apps.bard;
[*][b]Google App / Gemini Assistant[/b] — com.google.android.googlequicksearchbox;
[*][b]NotebookLM[/b] — com.google.android.apps.labs.language.tailwind;
[*][b]ChatGPT[/b] — com.openai.chatgpt;
[*][b]Claude[/b] — com.anthropic.claude;
[*][b]Grok[/b] — ai.x.grok.
[/list]

Для Google App используется локальный SNI-router: через Smart DNS направляются только домены Gemini и NotebookLM, а Поиск, Discover и Lens остаются на обычном соединении. Для отдельных приложений правила назначаются по UID.

Модуль [b]не меняет системный Private DNS[/b] и не направляет через Smart DNS весь интернет-трафик устройства.

[spoiler="Основные возможности"]
[list=1]
[*][b]Динамический Smart DNS через DoH.[/b]
Актуальные IPv4-шлюзы запрашиваются у нескольких Smart DNS через DNS-over-HTTPS. Полученный адрес принимается только после успешной TLS-проверки целевого домена.

[*][b]Независимый failover.[/b]
Gemini, NotebookLM, ChatGPT, Claude и Grok проверяются отдельно. Сбой одного сервиса не отключает остальные.

[*][b]Параллельная проверка резолверов.[/b]
DoH-источники опрашиваются одновременно: один зависший сервер не заставляет ждать сумму всех таймаутов.

[*][b]Резервный статический список.[/b]
Если DoH временно недоступен, модуль перебирает сохранённые шлюзы Smart DNS.

[*][b]Защита от QUIC и IPv6-утечек.[/b]
Для целевых UID блокируются UDP/443 и IPv6, чтобы приложения использовали управляемый TCP/IPv4-маршрут.

[*][b]Watchdog.[/b]
Демон контролирует SNI-router, обновляет UID приложений и каждые 30 минут повторно проверяет соединения. При проблеме включается быстрый повтор.

[*][b]Атомарное обновление firewall.[/b]
Цепочки обновляются через iptables-restore/ip6tables-restore без поочерёдного удаления рабочих правил.

[*][b]Per-app locale.[/b]
На поддерживаемых версиях Android для AI-приложений назначается en-US. Глобальный язык телефона не меняется; при удалении модуля прежние app-locales восстанавливаются.

[*][b]Multi-user и клоны приложений.[/b]
Учитываются UID основного пользователя, рабочих профилей и клонов приложений.

[*][b]Опциональные hosts и AdBlock.[/b]
При установке можно отдельно включить AI hosts-маршрутизацию и блокировку рекламы. Настройки сохраняются при обновлении.
[/list]
[/spoiler]

[spoiler="Настройка собственных Smart DNS"]
Штатный список находится здесь:
[code]/data/adb/modules/AIUnblock/smartdns.conf[/code]

Для собственных серверов скопируйте:
[code]smartdns.user.conf.example[/code]
как:
[code]smartdns.user.conf[/code]

Поддерживаемый формат:
[code]
DOH https://example.org/dns-query
DOT example.org
DNS 203.0.113.53
[/code]

[list]
[*][b]DOH[/b] — используется для динамического получения и TLS-проверки шлюза;
[*][b]DOT[/b] — сохраняет опубликованный DoT endpoint сервиса и отображается в диагностике;
[*][b]DNS[/b] — используется для обычного DNS-запроса и авторизации Smart DNS.
[/list]

Штатный и пользовательский списки объединяются, дубли удаляются. Некорректные строки пропускаются с записью в журнал. [b]smartdns.user.conf сохраняется при обновлении модуля.[/b]
[/spoiler]

[spoiler="Как это работает"]
После загрузки модуль:
[list]
[*]определяет UID установленных AI-приложений для всех пользователей;
[*]загружает штатный и пользовательский списки Smart DNS;
[*]выполняет обычные DNS-запросы для авторизации внешнего IP у Smart DNS;
[*]проверяет сохранённый шлюз;
[*]при его отказе параллельно запрашивает новые адреса через DoH;
[*]проверяет TLS и HTTP-ответы нужных доменов;
[*]атомарно применяет DNAT, SNI, QUIC и IPv6-правила;
[*]продолжает контролировать службу и периодически обновляет маршруты.
[/list]

Если рабочий шлюз временно не найден, модуль включает прямой режим и выполняет быстрые повторные проверки, не блокируя приложения навсегда.
[/spoiler]

Для чтения журналов необходим root.

[code]

Адрес 185.246.223.127 для gemini.google.com доступен (TLS verified, HTTP 200)
Выбран адрес Gemini: 185.246.223.127
Правила IPv4/IPv6, QUIC и SNI-router атомарно обновлены
[/code]
[/spoiler]

[spoiler="Установка и обновление"]
[list=1]
[*]Скачайте ZIP, не распаковывая его.
[*]Откройте Magisk, KernelSU / KernelSU Next или APatch.
[*]Выберите установку модуля из локального файла.
[*]Укажите [b]AIUnblock-v2.2.1.zip[/b].
[*]Выберите клавишами громкости нужные варианты hosts и AdBlock.
[*]После установки выполните полную перезагрузку телефона.
[/list]

При обновлении сохраняются install.conf, app-locales, выбранные шлюзы, proxies.override и smartdns.user.conf.
[/spoiler]

[spoiler="Удаление"]
Удалите AI Unblock RU через менеджер Magisk / KernelSU / APatch и перезагрузите телефон.

При удалении модуль останавливает службу, удаляет собственные iptables/ip6tables-цепочки, снимает монтирование hosts и восстанавливает сохранённые app-locales.
[/spoiler]

[spoiler="Ограничения и безопасность"]
[list]
[*]Доступность публичных Smart DNS зависит от их владельцев и хостинга.
[*]Шлюз видит внешний IP клиента, SNI и метаданные соединения, но при корректном TLS не получает содержимое HTTPS-трафика.
[*]DoH защищает DNS-запрос от обычного перехвата, но доверие переносится на выбранного оператора Smart DNS.
[*]Модуль не является полноценной заменой VPN и предназначен только для перечисленных приложений и доменов.
[*]При изменении API или доменов AI-сервисов может потребоваться обновление модуля.
[/list]
[/spoiler]
