# Список изменений Telegram WS Proxy

## v1.2.0 (1200) - Внедрение фирменного WebUI eCubz, динамического управления и экспресс-диагностики
* **Фирменный WebUI eCubz (`webroot/index.html`)**: полнофункциональный графический интерфейс для KernelSU Manager, MMRL WebUI X и APatch. Разработан в стилистике Material 3 Expressive (глубокий темный фон `#0f1318`, тональные поверхности, векторные Google Icons).
* **Исправление синхронизации моста KernelSU / APatch / MMRL**: устранена ошибка передачи объекта функции вместо строкового имени колбэка в `@JavascriptInterface` KernelSU, реализована универсальная поддержка асинхронных строковых колбэков, Promise и синхронного вызова.
* **Единая динамическая кнопка состояния**: кнопка автоматически переключается между «Запустить» и «Остановить» со сменой цвета, защитой от дребезга нажатий и блокировкой при выполнении («Выполняется…»).
* **Интерактивный блок донатов разработчика**: встроен в самый низ главного экрана и во вкладку «О модуле» с быстрым копированием реквизитов по клику (СБП / Т-Банк `+7 923 618-89-93`, Ю.Money `4100 1149 4875 904`, Crypto Bot `USDT/TON/GRAM`, TON Wallet).
* **Быстрые профили конфигурации в 1 клик**: пресеты «Энергосбережение» (`POOL_SIZE=1`, прямой WS), «Турбо-обход» (`POOL_SIZE=1`, Cloudflare first) и «Раздача по Wi-Fi» (`HOST=0.0.0.0`).
* **Экспресс-диагностика задержки Cloudflare (`action.sh ping`)**: быстрый однократный замер RTT до личного воркера (`CFPROXY_WORKER_DOMAIN`) и магистральных узлов Cloudflare (`cloudflare.com`, `1.1.1.1`, `workers.dev`) с цветовой индикацией качества связи.
* **Чистый JSON API статуса (`action.sh status_json`)**: гарантированно валидный вывод метрик для фронтенда и защищенный парсинг в WebUI.
* **Максимальная энергоэффективность (Zero Battery Drain)**: отсутствие постоянных фоновых процессов WebView и таймеров.
* **Умное поведение Action Button (`action.sh`)**: автоматический запуск WebUI в `KsuWebUIStandalone` или `MMRL`, с фолбэком в CLI и Telegram Intent.

## v1.1.0 (1100) - Комплексное исправление архитектуры и оптимизация
* **Общая библиотека функций `lib.sh` (T1)**: вынесен общий код валидации, управления процессами, блокировками и ссылками.
* **Перенос мутабельного состояния в `/data/adb/tg-ws-proxy` (T2)**: каталог модуля теперь read-only, настройки и постоянный ключ сохраняются при установках из recovery (N1, C6).
* **Единственный супервизор и блокировка (T3, К3)**: атомарная блокировка `supervisor.lock` исключает запуск дублирующих процессов и конфликт портов.
* **Абсолютный путь `MODDIR` (T4, N2)**: устранена ошибка относительного пути `$0` при вызове `action.sh` под Magisk.
* **Динамический пул Cloudflare-доменов (T5, К1, К2)**: включено авто-обновление списка из GitHub раз в час, удалены нерабочие статичные домены, исправлен синтаксис булевых флагов Go (`-cfproxy-priority=false`).
* **Контроль готовности сокета и Watchdog (T6, К6, N3)**: проверка открытия порта `127.0.0.1:1443` через `/proc/net/tcp`, сброс устаревших PID при смене `boot_id`, exponential backoff при сбоях.
* **Строгая валидация конфигурации (T7, М7)**: безопасный парсинг `PORT`, `HOST` и защита от шелл-инъекций.
* **Защита постоянного ключа (T8, С5)**: битый `SECRET` в `config.conf` больше не приводит к перезаписи сохранённого `secret.conf`.
* **Разделение потоков логов (T9, С2)**: демон автономно ротирует `tg-ws-proxy.log`, ошибки старта и паники сохраняются в `stderr.log`.
* **Интерактивный `action.sh` (T10, М4, М5)**: отображение статуса, сокета, активного домена, поддержка команд `status/start/stop/restart` и безопасный вызов `am start`.
* **Smoke-тест и поддержка 4 архитектур (T11, T12, М1, М2)**: добавлены сборки для `arm64-v8a`, `armeabi-v7a`, `x86_64`, `x86` с проверкой запуска при установке.
* **Безопасное удаление в `uninstall.sh` (T13)**: проверка PID через `/proc/<pid>/cmdline` перед завершением процессов и удаление `/data/adb/tg-ws-proxy`.
* **Честная документация и лицензия (T14, С7, С8, N6)**: созданы `update.json` и `LICENSE` (MIT) с атрибуцией Flowseal и spatiumstas, исправлено описание архитектуры (основной путь — прямой WS к Telegram, Cloudflare — резерв).
* **Мобильные значения по умолчанию (T15, С1, С3)**: `POOL_SIZE=1` (экономия заряда аккумулятора), `FAKE_TLS_DOMAIN=""` (чистый MTProto на loopback).

*Статус проверки:* Изменения проверены статически; работа на устройстве не проверялась.

## v1.0.0 (1000) - Первый релиз
* Первый релиз модуля для Magisk / KernelSU / APatch.
* Скомпилирован нативный демон на Go под ARM64 (`arm64-v8a`) и ARM32 (`armeabi-v7a`).
* Интерактивный `action.sh` для подключения прокси в 1 клик.
