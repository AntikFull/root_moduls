## <a name="english"></a> 🇬🇧 Description (English)

**NFQTTL Stealth Header & TTL Fix** is a Magisk / KernelSU / APatch module designed to bypass mobile carrier tethering restrictions and hotspot detection (Wi-Fi / USB / Bluetooth tethering).

### ✨ Features
- 🔒 **TTL / Hop Limit Locking:** Fixes IPv4 TTL and IPv6 Hop Limit values to prevent carrier hotspot detection.
- 🎭 **Stealth Header Modification:** Neutralizes carrier signature packets and tethering indicators.
- ⚡ **High Performance:** Native C/C++ `nfqttl` daemon ensures minimal CPU usage and full network throughput.
- 📱 **Multi-Architecture Support:** Fully compatible with ARM64, ARMv7, x86, and x86_64 Android devices.
