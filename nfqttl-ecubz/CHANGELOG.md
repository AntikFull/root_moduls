# Changelog / История изменений

## v8.4
- Добавлена полная поддержка устаревших версий Magisk (v20.4 – v23.0) через папку `META-INF`.
- Устранены ошибки `Unzip error` при установке на старые версии Magisk Manager.
- Нормализована упаковка ZIP-архивов с POSIX-слэшами для утилит `busybox unzip`.

## v8.3-fixed
- Оптимизация бинарника nfqttl и скриптов автозапуска.
