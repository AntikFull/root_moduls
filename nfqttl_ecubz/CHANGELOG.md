# Список изменений Nfqttl eCubz v15.0.2 (1502)

- Исправлено повреждение 32-битного бинарника `armeabi-v7a`: восстановлена корректная ELF-структура и контрольная сумма.
- Добавлена полная поддержка интерфейса точки доступа `wlan0` и маски `wlan+` в цепочках фильтрации FORWARD (`nfqttlb`), предотвращающая утечки Windows NCSI, NTP, телеметрии Microsoft и DNS-запросов на устройствах Samsung и других чипсетах.
- Исправлена логика запуска и восстановления NFQUEUE демона: на ядрах без нативного таргета TTL/HL (`HAS_TTL4=0`) watchdog гарантирует непрерывную работу и динамическую активацию правил при старте очереди.
- Добавлена строгая проверка SHA-256 контрольной суммы бинарников в `customize.sh` при установке модуля.
- Устранена ложная индикация "native TTL/HL" при отсутствии нативной поддержки в ядре устройства.

# Список изменений Nfqttl eCubz v15.0.1 (1501)

- Исправлен синтаксис TCPMSS clamping (`--clamp-mss-to-pmtud`) для предотвращения фрагментации и сбоев соединений.
- Динамическая синхронизация версий напрямую из `module.prop` без статического хардкода.
- Расширен диапазон фильтрации TLS Client Hello до 1600 байт для поддержки современных постквантовых шифров (Kyber/ECH).
- Интегрирована единая система логов Unified Logs (`logs/` в каталоге модуля и зеркало в `/sdcard/eCubz/logs/nfqttl_ecubz/`).
- Автоматический контроль целостности ELF-бинарников при установке.
- Оптимизирован жизненный цикл раздачи и восстановление правил при событиях netd.
