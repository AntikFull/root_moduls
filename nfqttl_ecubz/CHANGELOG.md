# Список изменений Nfqttl eCubz v15.0.1 (1501)

- Исправлен синтаксис TCPMSS clamping (`--clamp-mss-to-pmtud`) для предотвращения фрагментации и сбоев соединений.
- Динамическая синхронизация версий напрямую из `module.prop` без статического хардкода.
- Расширен диапазон фильтрации TLS Client Hello до 1600 байт для поддержки современных постквантовых шифров (Kyber/ECH).
- Интегрирована единая система логов Unified Logs (`logs/` в каталоге модуля и зеркало в `/sdcard/eCubz/logs/nfqttl_ecubz/`).
- Автоматический контроль целостности ELF-бинарников при установке.
- Оптимизирован жизненный цикл раздачи и восстановление правил при событиях netd.
