# Nfqttl eCubz

Nfqttl eCubz — модуль обработки TTL/Hop Limit и сетевых правил Android для сценариев раздачи мобильного интернета. Реальная совместимость зависит от прошивки, netfilter backend, tethering offload и доступных kernel targets.

## Основные возможности

* **Фиксация и подмена TTL:**
  При раздаче интернета через Wi-Fi или USB сетевые пакеты с подключенных устройств приходят на смартфон со значением TTL=64 или 128, а при прохождении через смартфон счетчик уменьшается на 1 (становится 63 или 127). Операторы отслеживают это изменение и блокируют раздачу.
  В текущем `service.sh` используется фиксированное значение **TTL/Hop Limit = 64**. Обработка выполняется нативными TTL/HL targets ядра, а при их отсутствии — через NFQUEUE, если очередь успешно поднята.

* **Входящая обработка и DNS Redirect:**
  При доступных kernel targets цепочка `nfqttlp` обрабатывает входящий IPv4/IPv6 трафик на распознанных upstream-интерфейсах. NFQUEUE-вариант входящей обработки включается отдельным флагом `ingressfix`. DNS Redirect **не включён по умолчанию** и активируется только файлом-флагом `dns_redirect`.

* **Широкая совместимость с интерфейсами:**
  Модуль полностью поддерживает специфические интерфейсы точек доступа (`wlan2`, `ap+`, `swlan+`, `softap+`, `rndis+`, `bt-pan+`) и каналы данных Qualcomm/MediaTek/Oplus (`rmnet_data+`, `r_rmnet_data+`, `rmnet_mhi+`, `rmnet_ipa+`, `ccmni+`).

* **Пользовательский список блокировки (blocklist.txt):**
  Файл `blocklist.txt` в каталоге модуля позволяет задавать пользовательские правила фильтрации.

* **Auto VPN Tethering (Раздача через VPN):**
  Автоматическое перенаправление трафика подключенных устройств в активный VPN-туннель (`tun0`, `wg*`, `awg*`, `vpn*`). При включении VPN на телефоне клиенты хотспота получают доступ в сеть через IPv4 VPN-канал с адаптивным TCPMSS Clamping и защитой от DNS-утечек (опциональным DNS override через файл `vpn_dns_server`). При отключении VPN раздача бесшовно возвращается на сотовую сеть.

* **Кнопка Action в Root-менеджере:**
  Позволяет в один клик переключать отладочный режим и генерировать файл диагностики `nfqttl_debug.log`.

## Совместимость

* **ОС Android:** Android 7.0 — Android 16 (архитектуры `arm64-v8a`, `armeabi-v7a`, `x86`, `x86_64`).
* **Root-менеджеры:** KernelSU, KernelSU Next, APatch, Magisk (v20.4+).

## v15.1.5: live VPN/Direct switching

- Auto VPN Tethering использует отдельную временную IPv4 routing table только для forwarded-трафика раздачи.
- При VPN ON downstream автоматически переводится в `tun0`/`wg*`/`awg*`; при VPN OFF module-owned route/rules удаляются и Direct Mode восстанавливается без перезапуска хотспота.
- Основной маршрут самого телефона не переписывается.
- Проверка состояния при активной раздаче выполняется раз в 1 секунду.

## v15.1.4: совместимость с виртуальными точками доступа и VPN-раздача

- Полная совместимость с виртуальными интерфейсами точек доступа (`wlan2`, `ap0`), где `/sys/class/net/<iface>/operstate` ограничен в правах чтения.
- Изоляция переменных в парсерах маршрутов ядра, предотвращающая потерю активных интерфейсов раздачи.
- Точное исключение uplink-интерфейсов из числа клиентов точки доступа (поддержка Wi-Fi Repeater / Bridge режимов через VPN).
- Транзакционная настройка и безопасный откат (Rollback) в прямой режим при любых сбоях настройки туннеля.
